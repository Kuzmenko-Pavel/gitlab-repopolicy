# gitlab-repopolicy

Server-side валідатор правил репозиторію для GitLab Self-Managed: глобальний `pre-receive` hook, який перевіряє кожен push за policy-файлами `PATHPOLICY`, `COMMITPOLICY` і `TAGPOLICY` із самого репозиторію.
